# 成語美食街

A Cantonese idiom-learning site for primary pupils, with Susu, Neko and 波波 (reborn dolls).

- Progress is saved automatically in the browser on each device.
- To move to another device, open 家長區 → 進度碼 and scan the QR code or type the code.
- No accounts and no server: nothing about the child is uploaded.

QR codes are generated with [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) (MIT).
